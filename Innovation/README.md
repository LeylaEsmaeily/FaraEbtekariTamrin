# Genetic Algorithm-based Key Optimization for Image Encryption

## 📌 Description

This project presents an experimental extension of an image encryption algorithm based on chaotic systems.

The proposed method replaces the Particle Swarm Optimization (PSO) algorithm with a Genetic Algorithm (GA) for optimizing the chaotic key parameters and evaluates its performance in comparison with the original PSO-based approach.

The goal of this project is purely educational and it was developed as part of a university coursework assignment.

## 📚 Features

- Chaotic key generation using Logistic Map
- Parameter optimization using Genetic Algorithm (GA)
- Image permutation and diffusion stages
- Encryption and decryption pipeline
- Comparative analysis between GA and PSO
- Security evaluation using Entropy, NPCR, UACI, Correlation Analysis, and Execution Time
